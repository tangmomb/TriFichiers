# TriVideosPhotos

Ce projet regroupe plusieurs scripts Python pour trier, déplacer, organiser et analyser vos photos et vidéos dans des dossiers.

## Installation

1. **Installer Python 3.7 ou plus récent**
2. **Installer les dépendances** :

Dans l'idéal, créez un envirronement et ouvrez un terminal dans le dossier du projet et lancez :

```
pip install -r requirements.txt
```

## Utilisation

Double cliquez sur `Launcher.bat` pour accéder à une interface graphique qui permet de choisir et exécuter les différents scripts :

### Fonctionnalités principales

- **Déplacer photos** : Déplace les photos d'un dossier à un autre avec validation par touches.
- **Doublons** : Détecte et envoie les doublons à la corbeille.
- **Nombre de fichiers** : Compte tous les fichiers d'un dossier et ses sous-dossiers.
- **Poids des vidéos/photos** : Calcule le poids total des images et vidéos.
- **Ramène à la racine** : Déplace tous les fichiers à la racine dans des dossiers dédiés.
- **Tri photos/vidéos** : Visionne et trie les fichiers avec possibilité de suppression.
- **Trouver fichiers d'une date précise** : Liste les fichiers modifiés à une date donnée.
- **Créer des sous-dossiers aléatoires** : Simule un désordre en répartissant les fichiers dans des sous-dossiers.

### Conseils

- Les scripts sont accessibles via le launcher, mais peuvent aussi être lancés individuellement.

## Dépendances

Les dépendances sont listées dans `requirements.txt` et installées automatiquement avec la commande ci-dessus.
