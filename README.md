# Tri de fichiers photos et vidéos

Ce projet contient des scripts Python permettant de **trier des fichiers photos et vidéos** présents sur votre machine de manière beaucoup plus rapide et efficace. Par exemple, ouvrir les fichiers d'un dossier 1 à 1, et décider en une touche si on garde ou si le fichier va à la corbeille.
